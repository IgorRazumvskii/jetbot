**Интеллектуальная робототехника. Домашнее задание 1**

**Написание ROS2-узла для движения робота до целевого объекта**

**Задание:** написать простой ROS2-узел для движения робота до целевого объекта. Это может быть любой легко узнаваемый объект небольшого размера, например, наклеенный на стену Aruco-маркер. Узел должен получать изображения с камеры, публикуемые драйвером из лабораторной работы 2, распознавать на них целевой объект и отдавать команды в топик /cmd\_vel\_nav для достижения целевого объекта. Распознавание целевого объекта может быть вынесено в отдельный ROS2-узел.

**Особенности реализации:**  
Узел должен иметь следующие ROS2-параметры:

- расстояние до целевого объекта, на котором робот должен остановиться  
- максимальные линейная и угловая скорости движения  
- реальный размер целевого объекта в метрах

Также должно быть реализовано поведение восстановления, если целевой объект потерян из поля зрения. Это может быть, например, медленное вращение на месте.

Узел должен работать совместно со стандартным teleop, чтобы была возможность перехватить управление движением робота. Для этого нужно создать launch-файл и в него добавить запуск ноды twist\_mux. У стандартного teleop должен быть приоритет, если команда cmd\_vel от него ненулевая. Если нулевая \- приоритет у достижения целевого объекта.

Для плавного управления роботом желательно использовать PID-регулятор (о них будет рассказано на лекции).

**Критерии успешного выполнения:**

Робот должен успешно доехать до целевого объекта и остановиться на расстоянии в интервале (0.75 \* stop\_distance, 1.25 \* stop\_distance), где stop\_distance \- заданный параметр. Кол-во успешных попыток \- не менее 4 из 5, при старте с разных позиций, с которых виден и распознается целевой объект. Также робот должен успешно восстановить движение до цели, если ему намеренно помешать с помощью teleop, выведя целевой объект из поля зрения. Он также должен восстановить движение до цели, если намеренно закрыть на время целевой объект другим предметом.
