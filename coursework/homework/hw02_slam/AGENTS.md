# ДЗ 2

- Воспроизводить rosbag локально в домене 82. Для прогона использовать один экземпляр SLAM. JetBot и его домен не участвуют.
- Из записи брать `/odom` и `/rslidar_points`. В исходном `/tf` есть старый `map → odom`. Для независимого восстановления запуск создаёт TF колёсной одометрии из `/odom` и статический TF лидара из измеренного монтажа. Новый `map → odom` публикует SLAM Toolbox.
- Сравнивать фактические сообщения `/map` и `/slam_path`, а также картинку демки. Качество оценивать по полному фрагменту. Результаты складывать в `results/`, датасет держать в `bags/`.
- `package/` содержит самостоятельный ROS 2 пакет. Демо использует существующий рендерер ЛР 4 из рабочего пространства Robotics. Комплект для сдачи включает видео из RViz.
- Экспорт демки сохраняет карту и путь по `/clock`, а видео и 3D-сканы берёт из того же rosbag по времени записи. Ползунок браузера читает готовые состояния вперёд и назад. Камера используется для просмотра.
