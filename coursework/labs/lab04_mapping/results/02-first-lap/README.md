# ЛР 4. Картирование после одного круга

20 ноября 2026 года. JetBot `jetbotj3` проехал один круг вокруг стола. Картирование запущено с чистого графа после установки робота на пол. Использован лидар с ограничением дальности 3 м и колёсный TF.

| Показатель | До заезда | После круга |
| --- | ---: | ---: |
| Размер карты, ячеек по 5 см | 105 × 97 | 141 × 105 |
| Ключевые кадры | 1 | 34 |
| Свободные ячейки | 3 091 | 7 548 |
| Занятые ячейки | 205 | 825 |
| Оценка x, м | −0,067 | −0,037 |
| Оценка y, м | 0,032 | 0,038 |
| Оценка курса, ° | −3,7 | 0,7 |

Между стартовой и конечной позой по данным SLAM получилось 3,0 см и 4,4° по курсу. Это расхождение оценок на одном заезде. Фактическое отклонение от отметки отдельно не измерялось. В графе было 33 связи. Срабатывание замыкания петли отдельно не подтверждено.

[Карта для просмотра](map.png), [растр PGM](map.pgm) и [метаданные карты](map.yaml). Сохранённый растр сверён по каждой ячейке с картой в пульте после заезда.

На JetBot карта и обе части графа сохранены в `~/robotics-course/data/lab04/first-lap`. Для запуска локализации нужны [файл графа](map_serialized.posegraph) и [данные сканов](map_serialized.data) с общим префиксом `map_serialized`.
